# Análisis de datos sobre la participación de las mujeres en la gestión del agua

## Autora

Isabel Chumi

## Descripción

Este repositorio contiene el análisis de datos realizado para la Tarea 2 mediante R, tidyverse, ggplot2 y Quarto.

El análisis utiliza datos de la investigación *Factores que inciden en la representatividad de las mujeres para la toma de decisiones en la gestión del recurso hídrico*, realizada por Chumi (2024).

## Datos

Los datos utilizados corresponden a una base de datos de 262 encuestas aplicadas a usuarios de diferentes tomas de agua de la Junta de Riego y Drenaje Machángara.

La base de datos se encuentra alojada en el repositorio de la Tarea 1:

[Datos_Analisis.xlsx](https://github.com/isabelchumip01-del/Tarea_01_Chumi/blob/main/Datos_Analisis.xlsx)

## Preguntas de análisis

- ¿Cuáles son los principales factores asociados con la participación de las mujeres en la toma de decisiones?
- ¿Cómo se distribuyen las mujeres integrantes de directivas dentro de la Junta de Riego y Drenaje Machángara?
- ¿Cómo se percibe la participación de las mujeres en comparación con la participación de los hombres en la gestión del agua?
